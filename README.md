# Модульная баня 6000×2500 — 3D-модель

Интерактивная 3D-модель модульной бани: комната отдыха, душевая, парная, терраса, зимнее окружение. Смоделировано в Blender по планировке заказчика.

## Скачать модель

- **GLB (готовая модель, 511 КБ):** https://gofile.io/d/gaH1Bc2w

Файл `banya_model.glb` открывается без установки программ:
- **Windows:** двойной клик → «3D Viewer» (встроен в Windows 10/11)
- **В браузере:** https://3dviewer.net — просто перетащите файл на страницу
- **Blender:** File → Import → glTF 2.0

## Состав модели

- **Комната отдыха:** Г-образная лавка с подушками, стол, два кресла, торшер, шторы
- **Душевая:** стеклянная перегородка, тропический душ, трап
- **Парная:** двухъярусные полоки из абаша с LED-подсветкой, печь-каменка с камнями, ведро
- **Экстерьер:** фасад из вертикальной тёмной доски, панорамные окна, плоская кровля со снегом, дымоход, терраса с дровником
- **Участок:** снежное покрытие

## Файлы в репозитории

- `build_banya_model.py` — скрипт-генератор модели для Blender (запуск: `blender --background --python build_banya_model.py`)

Габариты: 6000 × 2500 мм, высота потолков ~2,4 м.
